# SitPass

## Description
SitPass is an application for managing gyms and their working hours. It allows users to search for gyms, leave reviews, book appointments, and track their workouts. The app uses modern technology with Angular for the frontend and Spring Boot for the backend.

## Technologies I Worked With
- **Angular**
- **Spring Boot**
- **PostgreSQL**
- **JWT Authentication**


## Features

- Search for gyms by different criteria (city, discipline, rating, working hours)
- View the working hours for each gym
- Leave a review for a gym
- Show ratings for different aspects of the gym (equipment, staff, hygiene, rooms)
- View a list of workout appointments
- Create a user account and log in
